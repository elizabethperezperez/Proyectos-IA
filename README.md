# Proyectos-IA
Mini proyectos (vuluntarios) de la asignatura de IA.

El primer mini proyecto se encuentra en el archivo "MiniproyectoIA- 24-25.ipynb" este mini proyecto cubre los siguientes aspectos:
- Preprocesado de datos de un data set realizando la eliminación de valores faltantes y ajustando el conjunto de datos mediante Numpy, Pandas y la técnica ONE-HOT Encoding (para datos no numéricos).
- Escalado de datos mediante PCA y ajuste de hiperparametros GridSearch
- Uso del data set para el entrenamiento de algoritmos SVC, regresión logística, arboles de decisión y KNN
- Evaluación y métricas del algoritmo mediante curvas ROC, curva de aprendizaje, y matriz de confunsión.
(Para los últimos 3 algoritmos se ha usado la librería sklearn de python).


El segundo mini proyecto consiste en el entrenamiento de un modelo de convolutional neural network CNNs para la detección del tipo de flores (mediante el uso de las librerías de tensorflow, keras, pandas, numpy...), este proyecto se divide en 4 partes:
- Carga y visualización de datos.
- Entrenamiento de un modelo básico de CNNs.
- Técnicas de reducción del overfitting.
- Aplicación de Transfer Learning para mejorar el rendimiento.
